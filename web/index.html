How it works

One voice request. Real MCP all the way down.

Sous is a self-hosted MCP server. Alexa+ calls its typed tools over Streamable HTTP; every result carries a short spoken line plus an MCP App card for Echo Show.

  1. You speak. "Alexa, what's for dinner?" from across the kitchen, hands covered in flour.
  2. Alexa+ calls Sous over MCP. Streamable HTTP, spec 2025-11-25, typed tools with annotations and output schemas.
  3. Deterministic engines decide. Expiry ranking, the allergy guard and the cart token. The model never decides what's safe.
  4. Echo Show shows it. An MCP App card renders the result while Alexa speaks one short, voice-safe line.

What Sous does

A sous-chef that remembers, plans and shops.

Use-it-up planner

Ranks recipes by what expires first, so tonight's dinner rescues tomorrow's spinach.

Allergy guard

Hands-free cook mode

Giant steps on Echo Show, "next" and "back" by voice, named timers that chime.

Household memory

Allergies, dislikes and pantry state persist across sessions and across everyone in the family.

household_memory

Impact tracker

Dollars rescued, kilograms saved and CO2e avoided, week by week, with a yearly projection.
